## About

`tlsfp` passively captures TLS ClientHello and ServerHello messages, computes
JA3/JA3S and JA4/JA4S fingerprints, and identifies the client application or
library (browsers, curl, custom scripts) from a curated reference database,
without decrypting any traffic.
